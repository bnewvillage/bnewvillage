## What I Bring
- **Better decisions, faster.** Everything I build is there to make decision-making more accurate, more predictive, more reactive and quicker.
- **Turning business rules into data models.** I sit with the people who make the decisions, learn how they actually work, and encode that logic in SQL so the numbers match reality.
- **End-to-end pipelines.** Source system to warehouse to API to the screen someone uses. I've built and run the whole chain on my own.
- **Making messy data usable.** Large, inconsistent datasets with missing categories, mixed currencies and dirty keys. I clean them, structure them and infer what isn't there.
- **Applied analytics.** I pick the method that fits the question, whatever the domain: pattern and association mining, segmentation, forecasting, cost and return modelling. So far that's included market basket analysis on sessionized order history, sell-through and capital payback models, and demand-driven reorder logic.
- **Ship, test, iterate, repeat.** A working version goes in front of users fast. What holds up stays, what doesn't gets rebuilt, and the loop runs again.
